# Инструкция по запуску портала «Майноры ВШЭ» в Docker

В проект добавлены все необходимые файлы для сборки и запуска в изолированном Docker-контейнере:
- `Dockerfile` — многоэтапная сборка (Node.js 20 Alpine компилирует проект, а ультралегкий Nginx раздает статику, размер образа ~25 МБ).
- `nginx.conf` — конфигурация веб-сервера со сжатием Gzip, кэшированием и поддержкой SPA-роутинга.
- `docker-compose.yml` — запуск одной командой на порту 3000.
- `.dockerignore` — исключение лишних временных файлов и `node_modules` из контекста сборки.

---

## Вариант 1. Запуск через Docker Compose (самый простой способ)

В папке с проектом выполните:
```bash
docker compose up -d --build
```
После завершения сборки откройте в браузере:
👉 **http://localhost:3000**

Остановить контейнер:
```bash
docker compose down
```

---

## Вариант 2. Сборка и запуск через стандартные команды Docker

### 1. Сборка образа:
```bash
docker build -t hse-minors .
```

### 2. Запуск контейнера:
```bash
docker run -d -p 3000:80 --name hse-minors-app hse-minors
```
После этого сайт сразу доступен на **http://localhost:3000**.

Остановить и удалить контейнер:
```bash
docker stop hse-minors-app
docker rm hse-minors-app
```

---

## Вариант 3. Как передать готовый контейнер коллегам файлом (архивом)

Коллегам даже **не потребуется устанавливать Node.js, npm или скачивать исходный код проекта** — нужен только Docker.

### Шаг 1. У себя соберите образ и сохраните его в архив `.tar`:
```bash
# 1. Собрать образ
docker build -t hse-minors .

# 2. Сохранить готовый образ в один файл
docker save -o hse-minors.tar hse-minors
```

Получившийся файл `hse-minors.tar` (размером всего около 25–35 МБ) отправьте коллегам через Telegram, Google Диск, корпоративную почту или флешку.

### Шаг 2. Что нужно сделать коллегам (на Windows, Mac или Linux):
Коллегам достаточно открыть терминал в папке с файлом `hse-minors.tar` и выполнить две команды:

```bash
# 1. Загрузить готовый образ из файла
docker load -i hse-minors.tar

# 2. Запустить контейнер
docker run -d -p 3000:80 --name hse-minors-app hse-minors
```

После этого портал сразу откроется у них в браузере по адресу:
👉 **http://localhost:3000**

---

## Если порт 3000 уже занят
Если на компьютере порт 3000 занят другим сервисом, можно просто перенаправить на любой свободный порт, например 8080:
```bash
docker run -d -p 8080:80 --name hse-minors-app hse-minors
```
И открывать по адресу **http://localhost:8080**.
